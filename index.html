MISSION
すべての人に情報を届ける。

Webの読みやすさを一人ひとりが選べる環境をつくり、情報との接点をひらいていきます。

WHY ACCESSIBILITY

Webを見やすくすることから、情報との接点をひらく。

Webの見え方や読みやすさは、年齢、視力、利用環境、その日の体調によっても変わります。決まった一つの表示を押しつけず、利用者自身が文字や色、動き、読み上げを調整できることが大切です。

NANAiRO Accessibilityは、サイトを利用する人の選択肢を増やすことでWebアクセシビリティに貢献し、必要な情報をより多くの人へ届けることを目指します。

  • 01
    読みやすさを自分で選べる

    文字サイズ、間隔、コントラスト、フォント、読み上げなどを、その人に合った状態へ調整できます。

  • 02
    Web情報をより多くの人へ

    見え方や利用環境の違いによる負担を減らし、必要な情報へたどり着きやすくします。

  • 03
    アクセシビリティへの意識を広げる

    ツールの導入をきっかけに、コンテンツやサイト設計そのものの改善にもつなげていきます。

DOWNLOAD

サイトに合わせて、2つの導入方法。

難しい名前に見えますが、違いは「サイトをどのように管理しているか」だけです。制作会社や開発者が管理するサイトはnpm版、自分でHTMLやWordPressのテンプレートを編集できるサイトはCDN／セルフホスト版を選びます。

INSTALLATION

貼り付け方。

まず、サイトを作った担当者へ管理方法を確認してください。「ReactやVueを使っている」と言われたらnpm版、「HTMLまたはWordPressを直接編集できる」と言われたらCDN版です。

npm版

この作業は制作会社または開発担当者へ依頼できます

01
npm install ./nanairo-accessibility-0.1.0.tgz

import { init } from '@nanairo/accessibility';

init({
  locale: 'ja',
  position: 'right'
});

1. 担当者へ渡すダウンロードした.tgzファイルを、サイトを管理する制作会社や開発者へ渡します。

2. 組み込んでもらう担当者が上記のコマンドを実行し、サイトのプログラムへ追加します。

3. 全ページで確認右端に「表示サポート」が表示され、各機能が動くことを確認します。

CDN／セルフホスト版

HTMLやWordPressの共通部分を編集できる方向け

02
<script
  src="/assets/nanairo-accessibility.iife.js"
  data-nanairo-auto
  data-locale="ja"
  data-position="right"
  defer
></script>

1. ZIPを開く中にあるJavaScriptファイルを、画像などを置くサイトのフォルダへアップロードします。

2. コードを貼る全ページで共通するHTMLの</body>直前へ、上のコードをコピーして貼ります。

3. 表示を確認srcをアップロード先のURLへ合わせ、右端に「表示サポート」が出れば完了です。

OUR APPROACH

コンテンツを邪魔しない、機能のための透明感。

ガラス表現は操作パネルだけに限定し、本文には使いません。背景との関係を感じられる軽やかさと、文字を確実に読めるコントラストを両立しています。

01 · PERSONAL

必要な機能だけ

文字サイズ、高コントラスト、読みやすいフォント、音声読み上げ、メディア停止、読書ガイド。利用者が自分で選べます。

02 · RESPECTFUL

既存の操作を尊重

ブラウザや支援技術の操作を奪わず、OSの「透明度を下げる」「動きを減らす」といった設定も自動的に尊重します。

03 · PRIVATE

データを外へ送らない

閲覧内容や個人情報を収集せず、表示設定はブラウザ内だけで管理。外部アカウントを作らず利用できます。
