WHY ACCESSIBILITY

ウェブの接点を創る

情報インフラとしてのウェブサイトやオンラインサービスを、障害の有無や年齢に関わらず、誰もが自由に利用できるようにしたいと思っています。より多くの企業や行政、サービスがウェブアクセシビリティへの理解を深め、取り組めるように貢献したいと思います。

  • 01
    読みやすさを自分で選べる

    文字サイズ、間隔、コントラスト、フォント、読み上げなどを、その人に合った状態へ調整できます。

  • 02
    Web情報をより多くの人へ

    見え方や利用環境の違いによる負担を減らし、必要な情報へたどり着きやすくします。

  • 03
    アクセシビリティへの意識を広げる

    ツールの導入をきっかけに、コンテンツやサイト設計そのものの改善にもつなげていきます。

INSTALLATION

貼り付け方。

WordPressなら専用プラグイン版を選べます。「ReactやVueを使っている」と言われたらnpm版、通常のHTMLを直接編集できる場合はCDN版です。

npm版

この作業は制作会社または開発担当者へ依頼できます

01
npm install ./nanairo-accessibility-0.1.0.tgz

import { init } from '@nanairo/accessibility';

init({
  locale: 'ja',
  position: 'right'
});

1. 担当者へ渡すダウンロードした.tgzファイルを、サイトを管理する制作会社や開発者へ渡します。

2. 組み込んでもらう担当者が上記のコマンドを実行し、サイトのプログラムへ追加します。

3. 全ページで確認右端に「表示サポート」が表示され、各機能が動くことを確認します。

CDN／セルフホスト版

HTMLの共通部分を編集できる方向け

02
<script
  src="/assets/nanairo-accessibility.iife.js"
  data-nanairo-auto
  data-locale="ja"
  data-position="right"
  defer
></script>

1. ZIPを開く中にあるJavaScriptファイルを、画像などを置くサイトのフォルダへアップロードします。

2. コードを貼る全ページで共通するHTMLの</body>直前へ、上のコードをコピーして貼ります。

3. 表示を確認srcをアップロード先のURLへ合わせ、右端に「表示サポート」が出れば完了です。

WordPress版

管理画面だけで導入したい方向け

03
管理画面 → プラグイン → 新規プラグインを追加
→ プラグインのアップロード → ZIPを選択

1. ZIPを選ぶWordPress版のZIPを解凍せず、そのまま管理画面からアップロードします。

2. 有効化する「今すぐインストール」の後に「プラグインを有効化」を押します。

3. 表示を設定「設定 → NANAiRO Accessibility」で、日本語／英語とボタン位置を選びます。

OUR APPROACH

コンテンツを邪魔しない、読みやすさのためのデザイン。

操作パネルも、白を基調に青緑を添えた落ち着いたデザインに。細い枠線とゆとりのある余白で機能を整理し、説明文の読みやすさと操作の分かりやすさを大切にしています。

01 · PERSONAL

必要な機能だけ

文字サイズ、ダーク・ライトなどのカラーモード、読みやすいフォント、音声読み上げ、メディア停止、読書ガイド。利用者が自分で選べます。

02 · RESPECTFUL

既存の操作を尊重

ブラウザや支援技術の操作を奪わず、OSの「透明度を下げる」「動きを減らす」といった設定も自動的に尊重します。

03 · PRIVATE

データを外へ送らない

閲覧内容や個人情報を収集せず、表示設定はブラウザ内だけで管理。外部アカウントを作らず利用できます。
